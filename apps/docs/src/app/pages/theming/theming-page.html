Foundation

Theming

Vsechny DVision komponenty pouzivaji vyhradne CSS custom properties s prefixem --dvision-*. Pridej class="dvision" na <body> a premen libovolny token — zadna komponenta nema barvu natvrdo.

Jak pouzit

// styles.scss
@use '@dvision/angular/theme/dvision.theme';

// Vlastni tema — prepis libovolny token
.dvision {
  --dvision-primary:   #0066cc;
  --dvision-secondary: #00897b;
  --dvision-danger:    #e53935;
  --dvision-radius-md: 4px;
}

Barevna paleta

Kazda barva ma 4 varianty: zakladni, hover, subtle (pro pozadi) a text (kontrast).

@for (group of colorGroups; track group.label) {
{{ group.label }}
{{ group.base }} base
{{ group.hover }} hover
{{ group.subtle }} subtle
}

Povrchy a text

@for (t of surfaceTokens; track t.token) {
{{ t.label }} {{ t.token }}
}

Zaobleni

@for (r of radiusTokens; track r.token) {
{{ r.token }} {{ r.px }}
}

Stiny

@for (s of shadowTokens; track s.token) {
