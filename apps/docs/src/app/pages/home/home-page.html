DV ision

Moderní, tématovatelná knihovna komponent pro Angular. Postavená na CSS custom properties s vlastním design jazykem — žádný Material, žádný Bootstrap.

Prohlédnout komponenty Design tokeny
Angular 17+ Standalone Signals MIT

Rychly start

1

Instalace

npm install @dvision/angular
2

Import tématu

// styles.scss
@use '@dvision/angular/theme/dvision.theme';
3

Aktivace na body

<body class="dvision">
  <app-root />
</body>
4

Použití komponenty

import { DvCardComponent } from '@dvision/angular';

<dv-card variant="elevated">
  <div dvCardHeader>Nadpis</div>
  Obsah karty
</dv-card>
